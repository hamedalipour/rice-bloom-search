## 📖 **For New Deployments**

1. **Clone Repository**:
   ```bash
   git clone https://github.com/hamedalipour/rice-bloom-search.git
   cd rice-bloom-search
   npm install
   ```

2. **Setup Database**:
   - Run `FIX_BLOG_DATABASE.sql` in Supabase SQL Editor
   - Configure environment variables

3. **Deploy to Cloudflare Pages**:
   - Build command: `npm install && npm run build`
   - Output directory: `dist`
   - Node.js version: `18`
